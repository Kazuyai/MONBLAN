# Legacy Project JSON Format

MONBLANのプロジェクトJSONは、以前のバージョンで作業状態の保存に使用していた形式です。現在は利用者向けの保存形式をEAFに統一しており、JSONは既存データを移行するための読み込み互換としてのみ対応します。

JSONを読み込んだ後に`Ctrl+S`を実行すると、EAFの保存先を選択する画面が表示されます。以後は保存したEAFへ上書き保存されます。

## 対象

- 動画ファイル情報
- フレームレート
- 動画長
- 注釈レイヤー名
- 注釈データ
- EAFから読み込んだ場合の元XMLと対応情報

## 保存しないもの

- Undo/Redo履歴
- 現在の再生状態
- 選択中の注釈
- 選択範囲
- 類似動作候補
- AI処理中の状態

## スキーマ

```json
{
  "version": 1,
  "createdAt": "2026-09-04T00:00:00.000Z",
  "updatedAt": "2026-09-04T00:00:00.000Z",
  "videos": [
    {
      "name": "sample.mp4",
      "path": "C:\\videos\\sample.mp4"
    }
  ],
  "frameRate": 29.97,
  "videoDuration": 120.5,
  "layerNames": ["レイヤー1"],
  "eafTierIds": [null],
  "annotations": [
    {
      "id": "annotation-id",
      "startFrame": 1,
      "endFrame": 30,
      "text": "注釈",
      "layerIndex": 0
    }
  ]
}
```

## 注意点

- `path` にはローカル動画ファイルの絶対パスが入るため、他者と共有する場合は個人情報や研究データのパスが含まれないか確認する。
- 別PCで読み込む場合、保存された動画パスが存在しない可能性がある。その場合は動画ファイルを開き直す。
- `version` は今後の形式変更に備えた互換性管理用の値。
- `frameRate` が誤っていると、注釈の時間表示やエクスポート結果もずれる。
- EAFから開始したプロジェクトでは、未知の要素や参照注釈を保持して再出力するため、`eafSource`に元XMLを保存する。
- EAF自体には通常フレームレートが含まれないため、読み込み前に対象動画のfpsを確認して指定する。
- 他の注釈から参照される注釈層・注釈の削除は、EAF構造を壊さないため出力時に拒否する。
- 新しいJSONプロジェクトの作成・保存には対応しない。
