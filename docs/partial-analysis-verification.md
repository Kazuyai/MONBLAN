# 部分分析の手動確認チェックリスト

このチェックリストは、動作範囲検出と注釈補完の部分分析を、Windows + NVIDIA GPU環境で確認するためのものです。既存の動画全体分析を損なっていないことも同時に確認します。

これは動作保証や確認済み結果を示す文書ではありません。リリース担当者や開発参加者が、使用した環境と確認結果を記録するためのテンプレートです。検証には、公開・利用に問題のない動画を使用してください。

## 事前準備

- [ ] AI環境チェックが成功する
- [ ] 検証用動画のフレームレートと総フレーム数を記録する
- [ ] 1人だけ映る区間と、複数人が映る区間を特定する
- [ ] 注釈補完用のテンプレート注釈を1件作成する
- [ ] APIログを確認できる状態にする

```powershell
.\scripts\check-ai-environment.ps1
.\scripts\verify-ai-pipeline.ps1 -SampleVideoPath C:\path\to\sample.mp4
```

## 共通UI

- [ ] 分析区間の秒数表示とタイムラインの選択範囲が一致する
- [ ] 秒数の終了位置が選択範囲の右端と一致する
- [ ] 表示されたフレーム範囲が1始まり・両端を含む規約になっている
- [ ] 「再生位置で開始・終了」を逆順に設定しても小さい方が開始になる
- [ ] 前のステップへ戻る際に確認が表示され、戻ると後続の選択内容が破棄される
- [ ] 分析区間を変更すると人物を選び直すフローになる

## 動作範囲検出

### 動画全体

- [ ] 動画全体を選択して人物画像を取得できる
- [ ] 1人・複数人の選択が従来どおり動作する
- [ ] 人物、関節、注釈層を指定して検出を完了できる
- [ ] 結果の開始・終了フレームが元動画の位置と一致する

### 部分分析

- [ ] タイムラインで選択した区間から人物画像を取得できる
- [ ] 指定区間にだけ映る人物を選択できる
- [ ] 指定区間外にだけ映る人物が候補へ混入しない
- [ ] 検出結果が指定区間内に収まる
- [ ] 元動画基準のフレーム位置へ正しく復元される
- [ ] 分析区間の境界付近で1フレームのずれがない

### 短区間と異常系

- [ ] 1～4フレームの区間は人物選択へ進む前に案内される
- [ ] APIへ1～4フレームを直接指定するとHTTP 422になる
- [ ] 5フレーム以上では短区間検証を通過する
- [ ] 人物が存在しない区間では、区間変更を促す表示になる
- [ ] API失敗時にエラー内容と詳細ログの場所を確認できる

## 注釈補完

### 動画全体

- [ ] テンプレート注釈を1件選択できる
- [ ] 動画全体から人物画像を取得できる
- [ ] 人物と関節を指定して候補を検索できる
- [ ] テンプレートと重なる候補が結果から除外される
- [ ] 候補の個別挿入、削除、一括挿入が動作する
- [ ] 挿入した候補をUndoすると候補レイヤーへ戻る

### 部分分析

- [ ] テンプレート全体を含む分析区間を確定できる
- [ ] テンプレートを含まない区間はUIで拒否される
- [ ] テンプレートを含まないリクエストはAPIでHTTP 422になる
- [ ] 指定区間を使って人物画像を取得できる
- [ ] 候補が指定区間内に収まり、元動画基準の位置で表示される
- [ ] テンプレートより前だけ、後だけ、前後を含む各区間で検索できる
- [ ] 既存注釈と重なる候補が「重複」となり挿入されない

## AlphaPose結果の再利用

- [ ] 人物画像取得後、同じ動画・同じ区間の分析でAlphaPoseが再実行されない
- [ ] APIログでキャッシュ利用を確認できる
- [ ] 区間を変更すると、異なる区間のキャッシュとして扱われる
- [ ] 動画全体のキャッシュがある場合、部分分析でも人物IDが維持される
- [ ] 元動画を更新すると古いキャッシュが使われない

## MotionBERT結果の再利用

- [ ] 同じ動画・分析区間・人物で類似動作検索を再実行すると、2回目のログが `motionbert_cache_hit=True` になる
- [ ] 2回目のレスポンスに `motionbertCache: {"hit": true}` が含まれる
- [ ] テンプレートまたは関節だけを変更した場合も3次元姿勢データが再利用される
- [ ] 人物または分析区間を変更すると、初回は `motionbert_cache_hit=False` になる
- [ ] 同じ条件で動作範囲検出を行うと、レスポンスヘッダーとログでキャッシュ利用を確認できる
- [ ] 元動画、MotionBERT推論スクリプト、checkpointのいずれかを更新すると古いキャッシュが使われない
